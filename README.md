# 💰 Simpan Tabung Gaji

Aplikasi web modern, rapi, dan responsif bertema **Warna Oranye Segar (Orange Vibrant)** untuk mencatat penerimaan gaji, nama penerima, bulan gajian, serta mengalokasikan tabungan dengan cerdas dan teratur.

---

### ✨ Fitur-Fitur Utama:
1. **Input Data Gajian Lengkap**:
   - Nama Penerima Gaji
   - Bulan Gajian (`Bulan & Tahun` otomatis format Indonesia)
   - Jumlah Gaji Diterima (Format mata uang Rupiah otomatis)
   - Catatan / Pos Tabungan (misal: *Dana Darurat, Tabungan Menikah, Reksadana*)
2. **Kalkulator & Simulator Alokasi Tabungan Otomatis**:
   - Pilihan persentase (Preset Cepat: 10%, 20% Ideal, 30%, 50%, atau Slider bebas).
   - Opsi input nominal Rupiah langsung.
   - Perhitungan langsung antara **Nominal Uang Ditabung** vs **Sisa Kebutuhan Hidup**.
3. **Statistik & Ringkasan Keuangan Pintar**:
   - Total Gaji Masuk.
   - Total Tabungan Terkumpul.
   - Rasio Persentase Tabungan.
   - Total Alokasi Kebutuhan Hidup.
   - Daftar Jumlah Penerima.
4. **Visualisasi Grafik Interaktif (Chart.js)**:
   - **Grafik Batang (Bar Chart)**: Tren riwayat gaji masuk vs tabungan tiap bulan.
   - **Grafik Donat (Donut Chart)**: Rasio tabungan vs kebutuhan harian.
5. **Manajemen Data & Riwayat (CRUD)**:
   - Pencarian berdasarkan Nama atau Catatan.
   - Filter berdasarkan Bulan tertentu.
   - Edit dan Hapus catatan dengan konfirmasi aman.
   - Lihat & Cetak **Struk Bukti Tabung Gaji**.
6. **Ekspor & Impor Cadangan Data (JSON)**:
   - Data tersimpan aman di `localStorage` peramban Anda.
   - Dapat di-*backup* (ekspor) dan dipulihkan (impor) kapan saja.
7. **Desain Oranye Modern & Elegan**:
   - Menggunakan Tailwind CSS, Glassmorphism halus, ikon FontAwesome, dan animasi confetti saat menyimpan tabungan.
